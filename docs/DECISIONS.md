# Decisions

- Phase 7B source/core foundation uses actual DC historical election wards under dataset-specific CC BY 4.0, preserving raw bytes, year-level intervals and the original 1992/1990 label discrepancy. It does not represent global national borders. Geometry topology uses bounded sweep comparisons and preserves source arrays; source cuts keep all rings/parts. The initial opt-in visual morph is restricted to one simple Polygon without holes, uses deterministic 256-point correspondence and checks every candidate; incompatible shapes/multi-region partitions block rather than producing factual-looking invented borders. Project v15/editor/export gates remain pending; v14 application remains intact.

- Phase 7A.4 adds graphic manifest v1 and ZIP export without changing project v14. Actual post-paint WebGL2 depth readback avoids adding a style layer, which an initial test proved can alter beauty/depth ranges. RGB24 stores normalized GPU window depth with MapLibre layer priorities, not physical distance; overlays/captions have no invented 3D depth. Scene planes are unweighted, outgoing depth stays separate during crossfade, and reference frames preserve exact native rendering. Transparent DOM masks use opacity to retain caption measurement and restore changes in reverse order. Streaming STORE ZIP avoids extra PNG compression/memory, has explicit frame/pixel/entry/archive/time budgets and deterministic container timestamps. Final completion occurs only after cleanup/signal checks; cancelled artifacts cannot be reported as successful. Full P1/P2 release and external service/Adobe-host gates remain open.

- Phase 7A.3 introduces v14 with an actual v13 validator/migration, bounded immutable triangle meshes and same-scene model follow. Local untextured OBJ is the supported first asset format; GLB/FBX, remote materials, textures and skeletal animation are outside this contract. Declared units/up-axis/origin conversions and original-byte SHA are retained; authored CC0 aircraft geometry is illustrative. Polar/antipodal geodesics and Float32-collapsed triangles reject rather than producing invalid motion or blank meshes. A separate MapLibre custom WebGL2 adapter owns buffers/shaders, shared depth and nearest-world Mercator placement. Model AGL and follow-camera AGL sample the same verified DEM after readiness. Follow is pure evaluated state; original manual keys survive disabling follow. Close-view import/building focus and regional terrain presets explicitly disable follow when replacing camera keys. Source credit survives route snapshots, subsequent motion edits, interchange and reports. Native model preview keeps geometry detail identical to export. Models/follow do not complete multi-pass, cloud billing or historical data gates.

- Phase 7A.2 uses an immutable bounded building geometry/height registry and real MapLibre fill-extrusion layers. Schema v13 retains the actual v12 validator and adds empty registries/tracks during migration. Geometry and measurements retain source units and IDs; missing heights, absolute elevations, invalid rings/holes/parts and excessive topology work reject. Imports require explicit above-grade/rights review; no default height or fetched source URL is introduced. The City of Vancouver sample is a pinned, height-biased 100-element subset of generalized 2009 LiDAR, licensed for commercial reuse with required credit; it is not current architecture or a complete city inventory. Native full-canvas preview is used whenever a project has 3D buildings, preserving geometry resolution across editor/export. Height scale is a stylized evaluated measurement multiplier; source geometry updates only when the immutable dataset changes. Focus explicitly replaces current-scene camera keys and disables regional terrain in one undoable transaction. Models/follow/multi-pass remain separate gates.

- Phase 7A is split into independently validated terrain, buildings, models/follow and multi-pass modules. The first module uses nine original Sa Pa Terrarium tiles from the public AWS/Mapzen distribution, with pinned bytes/SHA, source notices and visible regional coverage. Project v12 retains the actual v11 validator and defaults old projects to disabled terrain. Full-resolution terrain preview is visually scaled so DEM detail/ground anchors match export; existing 2D scaling remains. No terrain-side min-zoom mutation alters the 2D renderer after an initial browser failure exposed setter constraints. Redundant layer movement/static route updates invalidated terrain texture caches; source/type/order signatures now update only when needed. Real H.264/PNG/seek parity passes with unchanged tolerances, while the measured 60-frame 1080p terrain render cost is 124.763 seconds on this machine. The source snapshot is geographic reference data and does not supply building heights/models or current survey accuracy.

- Phase 7D exports sampled camera metadata and baked 2D attachment nulls rather than claiming MapLibre's Web Mercator/perspective is an After Effects 3D camera. Immutable snapshots use the same MapRenderer readiness and projection as preview/export, including outgoing held-frame crossfades and collision visibility. Interchange v1 is independent of project v11, with explicit sample/JSON/deadline budgets. The trusted JSX template uses escaped UTF-16 literals and no eval/file/network/expression actions; per-frame Hold keys avoid unintended interpolation across scene cuts or the antimeridian. Actual JSON/JSX downloads and browser positions pass, while Adobe host validation stays open because the host is unavailable. Continue independent licensed 3D work without counting the host harness as Adobe validation.

- Phase 7C uses the installed signed-in Codex CLI, as explicitly selected by the user, without a separate API key or model override. Tools, shell, agents, plugins and browsing are disabled; proposals resolve source IDs against licensed local geography. Model output never supplies factual road geometry or historical polygons. The first live structured-output attempt rejected JSON Schema `oneOf`; disjoint type-literal branches now use equivalent `anyOf`, followed by strict Zod/source/timing validation. Place ranking prioritizes complete names before weak keyword matches after an actual model correctly refused missing IDs instead of inventing them. The prompt carries only a bounded summary/catalog, excluding original text/media. Generation UUIDs scope cancellation; Apply checks the original snapshot and locks and creates one undoable replacement. Actual model generation and actual rendering are separate gates from authored protocol tests.

- Phase 6K introduces schema v10 project-time audio/captions, preserving v1–v9 validators/migrations. Canonical embedded PCM WAV avoids remote media dependencies and codec expansion during arbitrary imports; sample rate/channels are retained within explicit budgets. Trusted browser microphone recordings alone enter a bounded decoding step. Fades/gain/source offsets use one timing model and summed audio hard-clips at ±1. FFmpeg duplicates mono into stereo explicitly to match Web Audio, then muxes real AAC/Opus. Captions compose globally above both crossfade scene planes. Playwright now owns an isolated storage directory and refuses to reuse unrelated dev servers, preserving user projects during test runs.

- Phase 6J introduces schema v9 Admin 1 references, retaining v1–v8 validation/migration. Stable `ne_id` becomes the internal ID; unmodified `adm1_code`, including irregular source codes, remains metadata. The pinned Admin 0 crosswalk resolves all parents. Country-split files retain every source coordinate/ring/island/hole and are verified by raw/file/geometry hashes. Only active countries load, with a project-wide eight-country budget and bounded streaming/checksums/readiness. Reference release 5.1.2 is shown explicitly because administrative divisions may since have changed. Opacity uses existing tracks and both crossfade renderers own their geometry resources. Real PNG equality and MP4 tolerance passed without relaxing comparison thresholds.

- Phase 6I introduces schema v8 datasets/choropleth and data-year tracks, retaining v1–v7 validation/migration. Fixed global color domains preserve comparison across years; observation interpolation/hold is labeled and never extrapolates outside each country's range. Country matching uses the exact pinned bundle catalog, with no fuzzy guessing. CSV/XLSX imports require provenance and explicit review. Bounded ZIP directory/size/CRC/XML/worksheet checks precede ExcelJS loading; cached formula values are rejected, unused media excluded and a disposable worker imposes a deadline. ExcelJS's uuid dependency is scoped to 11.1.1 to resolve its advisory while preserving v4 compatibility, exercised by real workbook tests. A PNG parity failure isolated 224 changed pixels to the CSS legend gradient, maximum channel error 2; the renderer now creates an opaque fixed-pixel ramp using the evaluator's color interpolation rather than relaxing pixel equality.

- English UI, Vietnamese Unicode text supported.
- Local Natural Earth geography; no OSM Foundation tile requests. Light, dark, muted styles use identical geometry.
- Schema v1 is the initial version; unknown versions are rejected rather than guessed.
- Node 24, pnpm 11. Source package exports avoid unnecessary build ordering for development.
- Phase 0 shell intentionally has disabled export until real rendering is validated.
- Shared accessible native controls and CSS currently replace Tailwind/shadcn and React Hook Form; all edits validate through Zod. Reorder uses keyboard-accessible up/down buttons rather than dnd-kit. These choices reduce UI dependencies while preserving behavior; draggable enhancements can be added without changing project contracts.
- Map vector geometry renders beneath DOM text/markers. Layer ordering is honored within each rendering plane; arbitrary interleaving needs a separate compositing implementation.
- Render workers use the production build on port 5174; editor development uses port 5173. A failed acceptance render exposed hot reload interrupting an active export. Production rendering removes that dependency.
- Phase 5 dependency audit prompted MapLibre 6.4.1 and Fastify 5.12.5. MapLibre now uses named ESM imports and a Vite-bundled local worker; WebGL2 is required. Production dependency audit has zero advisories after upgrade.
- Project zoom describes full-resolution framing; preview subtracts log2(canvasWidth/previewWidth), so resizing does not change geographic framing. User camera reads invert that correction. Screen anchors and map styles scale in project pixels.
- Post-MVP reliability review: renderer failures remain terminal until reload, including during updates and resize. Teardown ignores its own context-loss event. Each render-page load mounts a new renderer and rejects overlapping loads, so retrying failed initialization and loading another snapshot are deterministic. Unchanged editor transactions preserve undo/redo history; duration changes clamp the playhead.
- Phase 6A starts P1 with multi-scene editing and existing deterministic cuts. No schema fields or migration change. Structural scene edits create a contiguous sequence, keeping scene-local animation times; load/rename preserve imported gaps. Duplicates receive fresh scene/layer IDs. Trim discards later keys without rescaling remaining keys, and extension extends layer ranges that ended at the old scene end. Endpoint-key selection previews the last visible frame before an internal cut; direct seeking at the boundary uses the next scene. Crossfade awaits a separate compositing contract.
- Phase 6B adds independent template instances and atomic IndexedDB template updates. Camera presets create ordinary editable keys; orbit uses multiple short bearing segments so a complete turn cannot collapse under shortest-path interpolation.
- Phase 6C introduces schema v2 with tested migration from the actual v1 contract. Crossfade blends a held outgoing final visible frame with the live incoming scene; it does not shorten scene/project duration or shift local keys. The UI names this behavior explicitly. Two MapLibre renderers share the existing adapter and overlay implementation during the blend; export waits for both. Moving outgoing overlap transitions require a separate timing contract.
- Phase 6D introduces schema v3 scalar overlay transform tracks. V1/v2 validators remain available and migrations preserve original content while supplying empty tracks. Transform keys represent absolute scale/rotation/offset values; opacity keys remain multipliers. Transform animation is restricted to marker/text overlays; geographic polygon/path coordinates are not transformed in screen space. Styles emit ordinary editable keys and replace only affected properties. Scene trim processes every scalar property.
- Phase 6E introduces schema v4 for 60 FPS; v1–v3 migrate without altering their FPS or content. Existing 3840-pixel bounds support landscape/portrait 4K. A shared format registry drives API, worker and editor. GIF uses two-pass palette encoding to bound memory rather than a split graph retaining the entire sequence; centisecond timing/palette limits are disclosed. Temporary frame directories are unique and ownership-checked, including startup failure. Larger encoding passes have a bounded ten-minute timeout.
- The user explicitly confirmed complete P1 and P2 scope, including 3D, actual AI proposals and After Effects interchange. `docs/phases/phase-6/ROADMAP.md` now includes all later modules and external validation dependencies. Features requiring licensed datasets, credentials or host applications retain open gates until those resources are available and checked.
- Phase 6F introduces schema v5 shapes, retaining all previous validators. Cubic Bezier controls are WGS84 coordinates unwrapped before sampling; evaluated paths are separate from stored controls and share geodesic reveal with routes. These are illustrative graphics. Projected editor controls never enter render output and hide while another drawing tool is active, preventing controls from intercepting new geometry clicks. Browser click accuracy is checked in projected pixels because native clicks quantize to device pixels. A recovery-test font timeout exposed a race while removing Playwright network interception; the test now completes unrelated initial font requests and waits for active route handlers before removing interception.
- Phase 6G introduces schema v6 embedded static PNG assets and image layers. Existing migrations preserve content and add an empty registry. Source/author/license/credit declarations travel with pixels; no arbitrary uploaded SVG or remote URL executes. Built-in public-domain flags retain original bytes, including a UTF-8 BOM, and hash raw response bytes before rasterizing. PNG signature/chunk checks alone were insufficient: Chromium accepted deliberately corrupt compressed pixels, so bounded streaming inflate, exact scanline lengths/filter values and Adler checksum are validated before storage. Metadata-only validation cache is capped and returns copies. ImageResources retains active references only. Pattern pixelRatio and overlay dimensions use project pixels. Explicit font loading checks both weights before capture; failure tests block both WOFF2 and WOFF fallback. Procedural texture pixels have an explicit CC0 dedication.
- Phase 6H introduces schema v7 label collision with backward-compatible always-show defaults. Priority selection is stateless and uses full project pixels, not viewport DOM bounds; font measurements are bounded and refreshed after font readiness. Hidden marker text never hides its pin. Always-show labels reserve space; optional labels use priority, frontmost order and stable ID. Conservative rotated rectangles and four-pixel padding are deliberate. No anchor movement or previous-frame hysteresis is introduced. Text uses intrinsic width and explicit newlines to keep resize decisions consistent. Both crossfade scenes run the identical selection independently.

- Phase 6K introduces schema v10 self-contained canonical PCM16 WAV media with bounded registry and a combined 48 MiB UTF-8 JSON budget. Global project-time clips/captions do not move with scene crossfades. Web Audio and offline FFmpeg use the same half-open timing and linear gain model, explicit mono duplication and summed hard clipping. Recording is user-started, bounded and disposed on every exit. Integer measured caption placement avoids fractional compositor damage and preserves exact repeated-seek/PNG parity. Browser suites own their services and isolated storage; fake microphone hardware reads an authored CC0 WAV rather than a real microphone.

- Phase 6L introduces schema v11 optional marker/route source metadata with actual v10 migration. Offline Natural Earth place search works without accounts; hosted OSM-only search/road routing has a fixed HTTPS origin, memory-only credentials, bounded responses/deadlines, preserved quotas/cooldowns and explicit review. The user declined external accounts/keys and reiterated Codex as the AI source. Live routing verification remains open, and its absence does not count as completed road data. Continue independent Codex proposal work while external validation is unavailable; no repeated credential request or fabricated offline road geometry.
