# Decisions

- English UI, Vietnamese Unicode text supported.
- Local Natural Earth geography; no OSM Foundation tile requests. Light, dark, muted styles use identical geometry.
- Schema v1 is the initial version; unknown versions are rejected rather than guessed.
- Node 24, pnpm 11. Source package exports avoid unnecessary build ordering for development.
- Phase 0 shell intentionally has disabled export until real rendering is validated.
- Shared accessible native controls and CSS currently replace Tailwind/shadcn and React Hook Form; all edits validate through Zod. Reorder uses keyboard-accessible up/down buttons rather than dnd-kit. These choices reduce UI dependencies while preserving behavior; draggable enhancements can be added without changing project contracts.
- Map vector geometry renders beneath DOM text/markers. Layer ordering is honored within each rendering plane; arbitrary interleaving needs a separate compositing implementation.
- Render workers use the production build on port 5174; editor development uses port 5173. A failed acceptance render exposed hot reload interrupting an active export. Production rendering removes that dependency.
- Phase 5 dependency audit prompted MapLibre 6.4.1 and Fastify 5.12.5. MapLibre now uses named ESM imports and a Vite-bundled local worker; WebGL2 is required. Production dependency audit has zero advisories after upgrade.
- Project zoom describes full-resolution framing; preview subtracts log2(canvasWidth/previewWidth), so resizing does not change geographic framing. User camera reads invert that correction. Screen anchors and map styles scale in project pixels.
- Post-MVP reliability review: renderer failures remain terminal until reload, including during updates and resize. Teardown ignores its own context-loss event. Each render-page load mounts a new renderer and rejects overlapping loads, so retrying failed initialization and loading another snapshot are deterministic. Unchanged editor transactions preserve undo/redo history; duration changes clamp the playhead.
- Phase 6A starts P1 with multi-scene editing and existing deterministic cuts. No schema fields or migration change. Structural scene edits create a contiguous sequence, keeping scene-local animation times; load/rename preserve imported gaps. Duplicates receive fresh scene/layer IDs. Trim discards later keys without rescaling remaining keys, and extension extends layer ranges that ended at the old scene end. Endpoint-key selection previews the last visible frame before an internal cut; direct seeking at the boundary uses the next scene. Crossfade awaits a separate compositing contract.
- Phase 6B adds independent template instances and atomic IndexedDB template updates. Camera presets create ordinary editable keys; orbit uses multiple short bearing segments so a complete turn cannot collapse under shortest-path interpolation.
- Phase 6C introduces schema v2 with tested migration from the actual v1 contract. Crossfade blends a held outgoing final visible frame with the live incoming scene; it does not shorten scene/project duration or shift local keys. The UI names this behavior explicitly. Two MapLibre renderers share the existing adapter and overlay implementation during the blend; export waits for both. Moving outgoing overlap transitions require a separate timing contract.
- Phase 6D introduces schema v3 scalar overlay transform tracks. V1/v2 validators remain available and migrations preserve original content while supplying empty tracks. Transform keys represent absolute scale/rotation/offset values; opacity keys remain multipliers. Transform animation is restricted to marker/text overlays; geographic polygon/path coordinates are not transformed in screen space. Styles emit ordinary editable keys and replace only affected properties. Scene trim processes every scalar property.
- Phase 6E introduces schema v4 for 60 FPS; v1–v3 migrate without altering their FPS or content. Existing 3840-pixel bounds support landscape/portrait 4K. A shared format registry drives API, worker and editor. GIF uses two-pass palette encoding to bound memory rather than a split graph retaining the entire sequence; centisecond timing/palette limits are disclosed. Temporary frame directories are unique and ownership-checked, including startup failure. Larger encoding passes have a bounded ten-minute timeout.
- The user explicitly confirmed complete P1 and P2 scope, including 3D, actual AI proposals and After Effects interchange. `docs/phases/phase-6/ROADMAP.md` now includes all later modules and external validation dependencies. Features requiring licensed datasets, credentials or host applications retain open gates until those resources are available and checked.
- Phase 6F introduces schema v5 shapes, retaining all previous validators. Cubic Bezier controls are WGS84 coordinates unwrapped before sampling; evaluated paths are separate from stored controls and share geodesic reveal with routes. These are illustrative graphics. Projected editor controls never enter render output and hide while another drawing tool is active, preventing controls from intercepting new geometry clicks. Browser click accuracy is checked in projected pixels because native clicks quantize to device pixels. A recovery-test font timeout exposed a race while removing Playwright network interception; the test now completes unrelated initial font requests and waits for active route handlers before removing interception.
- Phase 6G introduces schema v6 embedded static PNG assets and image layers. Existing migrations preserve content and add an empty registry. Source/author/license/credit declarations travel with pixels; no arbitrary uploaded SVG or remote URL executes. Built-in public-domain flags retain original bytes, including a UTF-8 BOM, and hash raw response bytes before rasterizing. PNG signature/chunk checks alone were insufficient: Chromium accepted deliberately corrupt compressed pixels, so bounded streaming inflate, exact scanline lengths/filter values and Adler checksum are validated before storage. Metadata-only validation cache is capped and returns copies. ImageResources retains active references only. Pattern pixelRatio and overlay dimensions use project pixels. Explicit font loading checks both weights before capture; failure tests block both WOFF2 and WOFF fallback. Procedural texture pixels have an explicit CC0 dedication.
- Phase 6H introduces schema v7 label collision with backward-compatible always-show defaults. Priority selection is stateless and uses full project pixels, not viewport DOM bounds; font measurements are bounded and refreshed after font readiness. Hidden marker text never hides its pin. Always-show labels reserve space; optional labels use priority, frontmost order and stable ID. Conservative rotated rectangles and four-pixel padding are deliberate. No anchor movement or previous-frame hysteresis is introduced. Text uses intrinsic width and explicit newlines to keep resize decisions consistent. Both crossfade scenes run the identical selection independently.
