# Map data and fonts

Audio imports and voiceover require declared source, author, license and visible credit; recordings stay local until the user reviews/applies them. No third-party music is bundled. The authored synthetic PCM tone in `packages/project-schema/src/audio.fixture.ts` is dedicated under CC0-1.0 solely as a test signal, not represented as speech/music. Source declarations travel with samples in JSON/snapshots and `audioSources` reports; referenced unmuted audio retains source credit in rendered frames.

Natural Earth Admin 0 Countries, release v5.1.2, 1:10m, public domain. Source URL and SHA-256 hashes are in `data/countries/PROVENANCE.json`. Geometry is unchanged; attributes are reduced for local loading. Dataset boundaries reflect the source's point of view, not definitive territorial claims. UI and exports retain Natural Earth credit.

Natural Earth Admin 1 States/Provinces uses the same public-domain release v5.1.2. [Pinned source](https://github.com/nvkelso/natural-earth-vector/blob/v5.1.2/geojson/ne_10m_admin_1_states_provinces.geojson) and verified Admin 0 crosswalk produce 4596 regions in 251 country files. Raw hashes, file sizes/counts and geometry digest are retained in `data/admin1/PROVENANCE.json`; `scripts/fetch-admin1.mjs` reproduces the bundles without changing coordinates, holes or islands. [Source documentation](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/) describes reference coverage/accuracy and default de facto boundaries. Selection and output credit expose the release; administrative divisions/names may since have changed.

No external tiles, sprites, geocoding or routing services. Three styles are authored locally. Routes are geographic connections, not road directions. Terms: https://www.naturalearthdata.com/about/terms-of-use/.

Noto Sans is bundled through @fontsource/noto-sans 5.2.8 (SIL Open Font License 1.1), Latin and Vietnamese subsets, weights 400/700. The license is copied to `data/fonts/OFL.txt`. Font resources load from the same origin in preview and export.

Bundled Vietnam and Thailand flags use the original Wikimedia Commons SVG bytes. License pages, contributors, retrieval date and SHA-256 checksums are retained in `apps/web/public/assets/flags/PROVENANCE.json`. The Vietnam file is public domain under Commons' common-property/no-original-authorship declaration; the Thailand file is public domain under simple-geometry/common-property declarations. Sources: [Vietnam retained revision](https://commons.wikimedia.org/w/index.php?title=File:Flag_of_Vietnam.svg&oldid=1254205846), [Thailand retained revision](https://commons.wikimedia.org/w/index.php?title=File:Flag_of_Thailand.svg&oldid=1278665795). Built-ins are verified against their raw-byte hashes before rasterizing locally into project PNG assets. Original SVGs are not modified or accepted as arbitrary uploaded code. Visible credits accompany active assets in preview/export.

The procedural hatch/dot bitmap textures generated by AnimateMap Studio in `apps/web/src/imageImport.ts` are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). This dedication applies to those generated texture pixels. Imported user assets require an explicit source, author, license and visible credit; the application records that declaration without asserting ownership or verifying a user's license. Embedded image bytes and provenance remain in saved/exported project JSON and immutable render snapshots; render reports list asset sources separately from map provenance.

The country-name/code catalog in `data/countries/catalog.json` is derived from the same pinned Natural Earth features; tests verify exact correspondence. It supplies conservative import matching and no new boundary geometry. Country/year/value files require the user's explicit source/author/license/credit declaration. Test CSV/XLSX observations are authored illustrative numbers, labeled as synthetic and not measured statistics; their fixture data is dedicated under CC0-1.0. Interpolated/held values are labeled in the legend, and data source credits remain visible in exports.

XLSX import uses [ExcelJS 4.4.0](https://github.com/exceljs/exceljs/tree/v4.4.0), MIT; its notice is retained in `data/licenses/EXCELJS_MIT.txt`. fflate 0.8.3 supplies bounded PNG/ZIP inflate and ZIP repacking under MIT (`data/licenses/FFLATE_MIT.txt`). The lockfile pins dependencies; `exceljs>uuid` is overridden to the compatible patched 11.1.1. Workbook contents are read locally in a temporary worker; no geocoding or workbook URL is requested.

Natural Earth populated places v5.1.2 supplies the offline city gazetteer: 7,342 source Point coordinates and stable NE_ID values, with source/catalog SHA-256 in data/places/PROVENANCE.json. scripts/prepare-places.mjs validates the pinned raw source and preserves geometry coordinates. Data is public domain under Natural Earth's terms; names/places are release references, not current address or population assertions. Optional hosted geocoding restricts results to OpenStreetMap and retains ODbL-1.0/source IDs and copyright URL. Provider-derived road coordinates, profile, distance, graph metadata, retrieval date and response hash accompany imported routes; visible credit survives video/PNG. Provider configuration additionally requires account-specific storage/export terms confirmation. No provider is configured by default; no live routing claim is made. Contract test routes are explicitly synthetic fixtures and are not distributed as factual road data.
