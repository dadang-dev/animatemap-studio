# Phase 6I — Country/year/value data and choropleth

Status: passed locally after the label-collision gate.

Files/interfaces: preserve v1–v7 validators and add a versioned dataset registry plus a choropleth layer. Dataset records contain bundled country code, integer year and finite numeric value, with required source/author/license/credit and an optional unit. Reject duplicate country/year rows, unresolved countries, blank/non-numeric cells and dangling references. Store normalized records in JSON/templates/autosave/API/render snapshots; never embed workbook formulas or external URLs as executable content.

Import: local CSV and XLSX, with explicit country/year/value header mapping, worksheet selection and a review table before an undoable add. CSV handles quoted commas/newlines and UTF-8 BOM. XLSX uses a pinned licensed parser, with compressed/uncompressed size and entry limits checked before workbook loading. No XLS/XLSM, macros or formula evaluation. Require numeric values instead of trusting cached formula results. Match ISO code or an exact case-insensitive bundled country name; unresolved rows show their row number and country, and prevent applying incomplete data. Data import is local and makes no provider requests.

Animation: ordinary scene-local data-year keys on the Timeline. The pure evaluator samples year with the existing easing registry, then either linearly interpolates each country's observations or holds the preceding observation. No extrapolation beyond a country's observed range; missing values have an explicit color. A stable editable domain covers all imported values by default. Color interpolation and legend values are deterministic. Clearly label interpolated data; it is not a newly observed measurement.

Renderer/UI: MapLibre choropleth country fills and borders retain original geometry. Shared overlay renderer shows an optional screen-anchored legend with year, domain and unit plus source credit. Inspector changes dataset/year/sampling/domain/colors/legend; timeline supports data-year key add/move/copy/delete/easing and history/locking/trim. Delete unused datasets only after removing references.

Acceptance:

- [x] CSV/XLSX imports real records with source metadata; malformed/oversized/formula/unknown-country/duplicate data rejects with actionable row errors.
- [x] v1–v7 migration preserves projects; duplicate/missing dataset references, invalid values/year/domain/key timing reject.
- [x] Unit tests verify numeric/color interpolation, step sampling, missing values, constant-domain defaults, scene boundaries and repeat/reverse evaluation.
- [x] UI mapping/review, choropleth settings, keyframe/history/locking/trim and refresh/API/JSON/templates round-trip work.
- [x] Shared legend/source credits and real PNG/MP4 match preview at sampled data years and crossfade boundaries.
- [x] Static/unit/integration/build/format, dependency/license audit and appropriate browser regressions pass.

Risks: ambiguous country aliases, stale formula caches, workbook expansion/memory, misleading scale changes, uneven years and missing observations. No fuzzy geographic guessing. Default fixed-domain colors are comparable across years. The application records imported provenance without asserting the user's ownership.

Implemented limits: schema v8 stores up to five datasets and 10000 observations/project. Years are integer observations from 1–9999; keyframe years may be fractional within the dataset's observed range. Values are finite within ±1e15. Country catalog derives exactly from the pinned Natural Earth bundle, verified by test. Import supports 5 MiB UTF-8 CSV/XLSX input, at most 200 ZIP entries, 4 MiB/entry and 20 MiB expanded, ten visible/hidden worksheets, 64 columns, 100000 populated cells and 1000 characters/cell. ZIP central directory, actual expanded sizes and CRCs are checked before repacking bounded bytes into ExcelJS 4.4.0 (MIT). Extreme row/cell/sheet IDs, XML entity declarations, macros and external workbook links reject. Unused media is excluded. Work runs in a disposable module worker with a 15-second deadline; neither workbook formulas nor cached formula results become observations. ZIP layout reference: [PKWARE APPNOTE 6.3.10](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT).
