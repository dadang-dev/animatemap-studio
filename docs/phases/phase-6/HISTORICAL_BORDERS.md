Scope/data: start with **Washington, DC election wards, 1982–2011**: eight polygons in each of 1982–1991, 1992–2001 and 2002–2011. This is real administrative history, not worldwide national-border coverage. Keep original WGS84 response coordinates/properties, source identities, bytes/hash, server reprojection query, rights notices and year-level granularity. Risks: real snapshots differ substantially in vertex counts and boundary correspondence; direct index interpolation is unsafe. Accurate source retention and bounded topology checks take priority over enabling every morph. A morph is a visual effect, not reconstructed historical geography; even individually valid feature rings do not establish gap-free multi-region political partitions. Declare any such limitation clearly and reject unsupported cases rather than fabricating topology or geography.

Foundation results: the pinned compact pack is 2,085,655 bytes, with 24 original source polygons/selected properties and 53,215 vertices. Raw responses and dataset-specific item licenses are retained in `data/history`; preparation verifies source hashes and maps published ward numbers to stable logical IDs. A sweep-based bounded topology checker preserves original arrays, handles holes/islands/antimeridian comparison copies and rejects intersections/overlap/degeneracy/budget exhaustion. All real polygons passed; each era used fewer than 100,000 segment comparisons. Unit tests verify source bytes, exact geometry/properties, declared year coverage and unresolved 1990 labels.

Standalone pure evaluation selects exact source cuts by declared whole-year coverage and returns missing/blocked diagnostics instead of invented geometry. The initial illustrative morph supports **one simple Polygon region without holes**; source cuts still preserve Polygon/MultiPolygon/holes. It resamples 256 perimeter points, aligns orientation/world copy and chooses a deterministic cyclic correspondence, checks several preparation samples and validates the actual candidate at every evaluated time. Changed parts/holes, missing identity correspondence and multi-region partition morphs block with an explanation. The actual eight wards all produced valid, deterministic 50% 1982→1992 candidates; source arrays remain unchanged. This is an explicit limited first morph pipeline, not worldwide or partition-safe historical reconstruction.
