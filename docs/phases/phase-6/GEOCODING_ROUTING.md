A self-hosted routing origin, if implemented, is restricted to explicitly configured loopback and uses the same response/limits contract. Use explicit Search/Calculate actions, conservative local quotas, bounded inputs/response bytes/timeouts, serial requests, cancellation and actionable 401/429/timeout/invalid-response states. Responses must validate finite WGS84 values, geometry type/count/length, attribution and permitted source metadata before undoable application. Unknown/failed responses leave projects unchanged; geometry/provenance survives autosave/API/JSON and uses the existing renderer/export readiness. Credentials are entered through local provider configuration, not chat.
