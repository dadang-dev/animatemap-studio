# Phase 7D — After Effects camera/anchor interchange

Status: local artifact/UI acceptance passed; Adobe host validation pending. The reviewed Codex gate passed first. No After Effects executable was found in the standard 2025/2026 installation paths on this machine; actual host import/render acceptance remains open until an installed host can run the script.

Contract: sample the immutable validated project at `i/fps` using the existing evaluator and full-size MapLibre adapter. Emit a bounded versioned JSON manifest containing camera WGS84/zoom/bearing/pitch samples and projected 2D marker/text/image anchor tracks, plus a self-contained ES3-compatible JSX importer. The importer creates a composition, camera-metadata slider controls and animated 2D nulls with position/scale/rotation/opacity samples. It is executable code generated by the application from trusted templates; project strings remain escaped literals. It does not evaluate imported strings, execute commands, fetch network URLs or save/overwrite an AE project.

Projection: geographic camera metadata is not an After Effects 3D camera. MapLibre uses Web Mercator and its own perspective; output anchor tracks are baked composition pixels at the source resolution/frame rate. Keep the rendered map video as a separate ordinary footage import, retaining its attribution. Anchor nulls are attachment controls, not reproduced fonts, map geometry, captions or audio. Crossfade scene anchors retain distinct IDs and evaluated scene weights; outgoing anchors use the same held final visible state. There is no claim of editable country geometry, automatic 3D camera conversion or subframe match.

Files/interfaces:

- Shared typed interchange samples and trusted JSX emitter, with finite/order/budget checks and safe string serialization.
- MapRenderer read-only projected anchor sampling after existing readiness, including evaluated transforms and collision visibility; no change to animation semantics.
- Web export dialog owns an offscreen full-size renderer, cancellation/deadline/progress and JSON/JSX downloads. Snapshot does not modify the editor or saved projects; dispose resources on failure/cancel/close.
- Unit tests cover frame boundaries, cut/crossfade metadata, malformed/oversized samples, script literal injection and execution against an explicitly labeled host API contract harness.
- Real MapLibre browser tests compare exported pixel anchors to preview during pan/pitch/dateline motion, download actual artifacts and verify cancellation/resource failure preserves projects. The harness is not actual Adobe host validation.

Acceptance:

- [x] Deterministic validated camera/anchor sampling and bounded immutable artifacts.
- [x] JSON and executable JSX download through the interface, with documented instructions and projection limits.
- [x] Final static/unit/integration/browser regression after shared projection refactor; cancellation and resource failure scenarios pass.
- [ ] Actual After Effects host imports the JSX, creates expected keys and attaches a sample graphic to exported footage without projection drift.

Research: Adobe's [Scripts help](https://helpx.adobe.com/after-effects/desktop/automate-in-after-effects/automate-animation/scripts.html) documents JSX and File → Scripts → Run Script File and links its scripting guide. That [LayerCollection reference](https://ae-scripting.docsforadobe.dev/layer/layercollection/) documents null creation; [Property reference](https://ae-scripting.docsforadobe.dev/property/property/) documents parallel keyframe arrays and interpolation. Use stable ExtendScript APIs rather than the separate UXP 27.0 API. No automatic host invocation is attempted while the host is unavailable.

Implementation: animation-core's separate `afterEffects.ts` validates interchange v1 without changing project v11 or migrations. It exports an anchor registry, camera/frame samples, provenance credits and an ASCII-only trusted JSX template; Unicode strings become escaped UTF-16 literals, including surrogate pairs. No eval, network, shell, expressions or file writes occur in the script. One Undo group owns newly created composition/nulls; script failures remove the new composition and end the group. Slider controls are geographic metadata, and nulls have Hold keys at each source frame. Position samples include overlay offsets; scale/rotation remain separate attachment properties. A shared MapRenderer projection method serves both drawn overlays and exported samples.

Web collection clones and validates the project before sampling, owns an offscreen renderer at the actual canvas resolution, waits for the same resources on each frame, includes outgoing crossfade anchors/weights and disposes on completion/cancel/close/failure. Limits: 100 anchors, 250000 frame×anchor samples, 18000 frames, 32 MiB JSON, ten-minute deadline. Sampling does not seek or edit the visible project. Font/geometry/image failures reject rather than returning partial artifacts. Zod 4.1.13 is explicitly pinned in animation-core; the offline install initially lacked registry policy metadata, and a normal install verified the unchanged dependency versions.

Validation: `pnpm check` passed 123 unit/integration tests in 41 files, strict TypeScript/lint/build. Three module/foundation browser scenarios passed in 51.5 seconds: actual MapLibre sampling/download, exact repeated JSON, preview position parity, dateline movement, pitched camera, Unicode, collision-hidden text, image anchors, crossfade, cancellation/close and a real missing Admin 1 resource. The 90-frame/8-anchor JSON and self-contained executable JSX were downloaded through the interface. Maximum position error at frames 0/30/60/67/75/89 is below 0.005 pixels (tolerance 0.01); adjacent `after-effects-parity.json` records the comparison. Ignored `.local/reviewed/after-effects/` retains JSON, JSX and reviewed preview. The explicit host API harness executes the emitted code to verify key arrays, literal injection safety and cleanup; it does not substitute for actual Adobe validation. Initial unit fixtures used a duration shorter than the existing one-second project minimum; correcting the fixture fixed that test-contract error without relaxing application validation.
