# Phase 7A.3 — Local 3D mesh assets and deterministic object follow

Status: completed. Terrain and buildings passed their separate gates. No additional accounts/API keys are required.

Files/interfaces:

- Project v14 retains the actual v13 validator/migration. Add a bounded immutable 3D mesh asset registry with explicit source/license/credit, file SHA, units, source up axis and placement-origin derivation. A model layer references an asset, stores stationary WGS84 anchor or illustrative geodesic motion path, above-ground altitude, heading/pitch/roll, color and evaluated opacity/scale/path-progress tracks. Camera follow references an existing model within its scene and uses deterministic position/heading plus bounded camera settings.
- First asset pipeline imports **local untextured triangle OBJ** in a disposable bounded worker, preserving source positions except declared up-axis/origin conversion. Reject external material/image references, code, unsupported primitives, invalid indices, degenerate/non-finite geometry and excessive triangles/bytes. This deliberately small supported format does not claim GLB/FBX/textured/skeletal compatibility. An authored CC0 vehicle mesh demonstrates actual 3D rendering and carries its own provenance; it is a stylized asset, not measured architecture.
- A separate MapLibre custom WebGL2 adapter owns real buffers/shaders, shared 3D depth, deterministic Mercator placement and resource disposal; no wall-clock animation. Native canvas preview is used for model projects. Above-ground placement samples the same local terrain as preview/export after readiness. Source credits appear in video/PNG/interchange/reports.
- Library/source review, shared Inspector, editable timeline, route-to-motion snapshot, follow controls, locking/history, scene trim, autosave/templates, API persistence and JSON use the same schema/evaluator.

Limits: source units must be declared; asset sizes are illustrative, not geospatial measurements. Paths are geographic connections, not unverified road directions. Ground-centre placement is an explicit derivation; preserve-origin remains available. Follow replaces evaluated camera centre/bearing only for its chosen scene; stored camera keys remain available after disabling it. Turns at path corners follow the chosen geometric path; no invented road spline is asserted. Models/mesh graphics do not constitute multi-pass or historical data completion.
