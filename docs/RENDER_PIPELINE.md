# Fixed-frame export

Schema v9 Admin 1 highlights and optional outlines load only from fixed bundled country files. Each renderer verifies pinned bytes/SHA-256 and waits for geography before capture, including outgoing crossfade frames. Missing/corrupt files produce actionable failures; saved snapshots/projects remain intact. Source metadata and selected country file checksums/counts appear in `admin1Source` in the render report; visible credit identifies release 5.1.2.

Schema v8 snapshots include country/year/value datasets and provenance. The evaluator samples data-year tracks and calculates colors before the shared MapLibre adapter applies fills/borders. Legends, observation/interpolation status and source credit use the same DOM renderer in preview/export. The legend color ramp uses fixed opaque pixel values instead of compositor-dithered CSS gradients. Render reports include active `datasetSources` metadata/counts without duplicating observations. Workbook parsing is an editor import operation; workers render only validated normalized project records.

`POST /api/jobs` accepts `{project, format: "mp4"|"png"|"webm"|"gif", frameIndex?}`. It validates and clones the project. `GET /api/jobs/:id` reports status/progress; POST `cancel` or `retry`; GET `download` returns an actual completed file with schema-defined MIME/extension. One worker runs at a time; up to five active/queued jobs are allowed.

The worker opens `/render` on the production preview server at 127.0.0.1:5174, at the project's exact dimensions with deviceScaleFactor 1. `pnpm dev` builds this server before launching services, insulating exports from Vite's editor hot reload. Restart services after renderer code changes. `window.renderStudio.load(project)` initializes the same MapSurface/MapRenderer as the editor. `frame(i)` calls the shared pure evaluator at i/fps, applies an instant camera jump and layer state, then waits for fonts and map resources with timeouts. Map style transitions and tile fades are disabled. All requests are restricted to the local origin.

MP4 contains ceil(duration×fps) PNG captures encoded by shell-free FFmpeg with libx264, yuv420p, CRF 18 and faststart. PNG uses the chosen frame index. Snapshots/reports/outputs are retained under the local render directory; temporary frames are removed on success, cancellation and error. Cancellation closes Chromium and terminates FFmpeg. Frame readiness gets one retry. Job status is in memory; restarting the API abandons jobs, but never modifies saved projects.

WebM uses libvpx-vp9, CRF 18, zero target bitrate and yuv420p. GIF generates a global palette in one pass, then reads captures again with paletteuse/Bayer dithering and infinite loop metadata. This avoids buffering an entire 4K sequence in a split filter graph. GIF delays use centisecond precision, and the final delay is rounded to the nearest centisecond. All video/animation formats preserve the same N captures and dimensions. V4 permits 60 FPS and retains 3840-pixel bounds in both axes. MP4/WebM require even dimensions; PNG/GIF permit odd dimensions.

Encoder argument construction is isolated in `apps/render-worker/src/encoders.ts` and never uses a shell. Each encoding pass has a ten-minute timeout. Capture/palette files live in a unique `frames-*` directory; deletion verifies its absolute parent and name prefix. Chromium startup failure and cancellation also clean owned temporary files while retaining snapshot/project/user files. Larger exports require proportionally more disk/time; this remains one local worker.

Schema v2 crossfades use the evaluator's outgoing final visible frame and live incoming state. The shared compositor creates a secondary inert MapRenderer only during the transition, blends by project time, and waits for both maps/fonts before capture. No CSS transition or wall clock controls the blend. The held outgoing frame preserves existing scene durations and local animation timing.

CLI: start `pnpm dev`, then `pnpm render examples/travel-vietnam.json .local/travel mp4`. FFmpeg/ffprobe must be on PATH; optional FFMPEG_PATH overrides the encoder executable.

Schema v6 snapshots embed normalized static PNG bytes and provenance. The shared renderer waits for active image decodes, overlay clones, both Noto Sans weights/subsets and map readiness, including both crossfade renderers. Every resource stage has a bounded timeout and descriptive failure; unavailable bundled fonts fail rather than silently exporting a fallback. Country pattern pixelRatio matches preview scaling. Credits include active image/texture sources. Reports expose `assetSources` metadata without duplicating encoded image bytes; source URLs are declarations and never requested by the worker. JSON/PNG validation precedes job creation and failure leaves saved projects intact.
